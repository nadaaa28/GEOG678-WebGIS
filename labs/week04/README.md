## JavaScript and JSON: Finding a Bounding Box

This assignment uses JavaScript functions, loops, and conditional statements to calculate the bounding box of five points. The results are stored in an object containing the top-left, top-right, bottom-left, and bottom-right corners.

## Files

- [HTML page](index.html)
- [JavaScript code](script.js)
- [Input data](data.js)
- [Console screenshot](console-output.png)

## How to Run

1. Download the HTML and JavaScript files into the same folder.
2. Open index.html in a browser.
3. Open the browser's Developer Tools and select Console.
4. Click Calculate Bounding Box to display the email address and output object.
