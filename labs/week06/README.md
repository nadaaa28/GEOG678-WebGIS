## Results

| Map | Result |
|---|---|
| Using GeoJSON with Leaflet | The map displays GeoJSON features in Denver, including bicycle rental locations, a bus route, and Coors Field. Clicking a feature opens a pop-up with information. |
| Interactive Choropleth Map | The map displays US states in different colors based on population density. Hovering over a state highlights it and displays its name and density. Clicking a state zooms to it. |
| TAMU Campus Map | The map displays TAMU buildings in maroon. Hovering over a building highlights it and displays its name and abbreviation. Clicking a building zooms to it. |
